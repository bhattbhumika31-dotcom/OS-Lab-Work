## About This Repository

This repository contains the implementation of **13 Operating Systems Lab practicals** using the C programming language.

The practicals cover fundamental Operating System concepts such as process management, inter-process communication (IPC), CPU scheduling algorithms, and page replacement algorithms.

## List of Experiments

### 1. Process Management

| No. | Experiment |
|---|---|
| 1 | Implementation of `fork()` system call |
| 2 | Program to calculate the sum of odd numbers in the parent process and even numbers in the child process using `fork()` |
| 3 | Implementation of `wait()` system call |
| 4 | Implementation of Orphan and Zombie processes |

### 2. Inter-Process Communication (IPC)

| No. | Experiment |
|---|---|
| 5 | Implementation of Pipe |
| 6 | Implementation of FIFO (Named Pipe) |
| 7 | Implementation of Message Queue |
| 8 | Implementation of Shared Memory |

### 3. CPU Scheduling Algorithms

| No. | Experiment |
|---|---|
| 9 | First Come First Serve (FCFS) Scheduling |
| 10 | Shortest Job First (SJF) Scheduling – Non-Preemptive |

### 4. Page Replacement Algorithms

| No. | Experiment |
|---|---|

| 13 | LRU Page Replacement Algorithm |
